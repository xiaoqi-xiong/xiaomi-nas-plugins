# 设计参考与验证

系统监控和 Docker 页参考用户提供的 fnOS 信息组织方式：顶部资源概览、时间曲线、存储与网卡、容器分组和详情。所有界面、图标和兼容代码由本项目实现；没有复制 fnOS 代码、品牌素材或截图。私人设备截图不随公共仓库分发。

搜索下载保留 qB 和 PanSou 的既有功能，以桌面侧栏和手机底部标签聚合；MoviePilot 与代理继续独立。音乐使用 Songloft 官方 API，自有播放器界面与服务分离。

建议验证尺寸为手机 390×844 和桌面 1440×900，检查文字、按钮、页面滚动、iframe、登录表单和错误提示。监控需覆盖首次/重置/离线/陈旧样本、Docker 无权限与空列表；音乐需覆盖未配置、离线、登录失败、正常曲库和 Range 播放。每个指标都必须有真实数据来源或明确的不可用状态。

本地 `scripts/preview_suite.py` 仅提供带显著标签的模拟数据，绑定回环地址，不读取 NAS 或私人配置。页面截图用于验证响应式布局和交互，不能证明实机部署。

## 已遇问题与回归要求

| 已遇问题 | 固定处理方式 | 验收证据 |
| --- | --- | --- |
| 应用内返回只能返回其内部页面 | 外壳统一调用小米 `normal_goback`，内嵌页面不接管 | 点击只调用一次，拖动不触发返回；实机另验 |
| 返回按钮挡住操作或出现多个 | 一个可拖动悬浮按钮，边缘吸附，预留底部区域 | 旋转、切标签、打开设置后仍可用 |
| iframe 隐藏后仍占位 | `[hidden]` 显式隐藏 | 只有当前标签可见 |
| iframe 默认高度只剩 150px | 外壳到内容区完整的确定高度链 | 320/390px 手机和横屏都能滚动查看任务 |
| 长文件名撑宽手机或设置按钮够不到 | 名称换行/省略，设置面板独立滚动 | 查看做种筛选、保存位置和限速 |
| HTTP 错误页被当作成功载入 | 网关插入错误标记，外壳显示重试 | 模拟上游错误不能显示成功 |
| 两个下载器的任务、登录或代理混用 | 仅合并界面，固定上游及独立会话保持不变 | 分别检查任务、保存位置、限速；PT 保持直连 |
| 缺失指标显示 0 或把累计值当速率 | null 显示未知；单调时钟计算差值；Docker I/O 标累计 | 首次采样、重启、重置、过期和缺失测试 |
| 把内核或 OS 版本当作固件 | 固件仅取明确来源，否则显示未知 | 总览标签和字段对应正确 |
| 音乐服务故障被当成未配置 | 分开处理配置缺失、HTTP 失败、播放失败 | 离线提示与退出登录时停止播放 |
| 固件升级后 SSH/插件失效，被误判为 IP 问题 | 分别检查当前租约、端口与原生插件入口 | DHCP 保留不等于服务恢复；不盲目重跑 Root |
| 私有教程、凭据和模拟状态混进发布包 | 公共源文件白名单、独立私有配置、模拟器仅回环监听 | 包清单与发布前隐私检查 |

本轮本地浏览器验证覆盖 320×740、390×844、844×390、1440×900，使用真实 UI 与模拟后端。已检查页面身份、非空渲染、错误状态、图片资源、任务筛选、设置、服务切换、音乐模拟播放和退出；共享返回用 `?native=mock` 验证请求契约，真实小米客户端退出仍属于上线验收。

模拟器的 qB 修改 API 返回 405，不会改变真实任务。`?native=mock` 的可见返回计数只用于开发验证，不进入生产 CGI。
