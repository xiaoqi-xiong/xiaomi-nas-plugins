# Security policy

Please do not publish credentials, API keys, controller secrets, cookies, private subscription URLs, device logs, or NAS backups in issues or pull requests.

Report a security issue privately to the repository owner through GitHub's security advisory feature. Include a concise description and reproduction steps without real secrets or personal data.

Supported versions are the latest source on the default branch. The project is maintained on a best-effort basis and does not provide a guaranteed response time.
